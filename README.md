# Фасады онлайн — прототип сервиса заказа

Кликабельный прототип сервиса, в котором заказчик собирает спецификацию на мебельные фасады и оформляет заказ сам, без менеджера.

**Демо:** https://elijah3737.github.io/fasady-online-prototype/

## Что внутри

| Экран | Что показывает |
|---|---|
| Витрина | С чего начинается заказ |
| Расчёт — «Пошагово» | Материал → декор → фрезеровка → размеры, с живым превью фасада и ценой |
| Расчёт — «Списком» | Табличный ввод партии: массовые размеры, вставка столбцов из Excel, общий итог |
| Заказ | Спецификация позиций, площадь, сумма |
| Оформление | Контакты, способ получения, оплата картой или счётом |
| Статус | Трекер этапов: принят → в производстве → готов → выдан |
| Мои заказы | История заказов, повтор заказа, спецификация в PDF |

## Как устроено

Один самодостаточный HTML-файл: разметка, стили и логика внутри, внешних зависимостей нет (кроме веб-шрифта). Состояние живёт в памяти страницы — обновление сбрасывает корзину. Экраны различаются по адресу (`#cfg`, `#cart`, `#orders`), поэтому работает кнопка «назад» и ссылку можно отправить на конкретный шаг.

Печать спецификации использует системный диалог печати: в Safari — «Печать» → «Сохранить как PDF».

## Границы прототипа

Цены **условные**, оплата не проводится, бэкенда нет. Демонстрируется сценарий и интерфейс, а не боевой расчёт: в рабочей версии подставляется прайс производства, а заказ попадает в его учётную систему.
