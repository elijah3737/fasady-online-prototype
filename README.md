  контрагентов, второй со скидкой 50%), спецификация с валидацией по
  техкарте выбранной фрезеровки, декоры с наличием, мои заказы со
  статусами и повтором, документы, акт сверки (печать).
  Прямые ссылки: `cabinet.html#demo` (базовая цена), `#demo-dd` (со скидкой).
- `admin.html` — экран менеджера: заказы, смена статуса, KPI,
  «заказ от имени контрагента» (демо).

## Грабли
- URL CDN содержит скобки → в CSS `url()` кавычить; **в инлайновом
  `style="…"` двойные кавычки внутри двойных рвут атрибут** — атрибут
  собирать с одинарными.
- Из карточек Nethouse `src` тянуть до пробела: там srcset «URL 1x, URL 2x».
- Хэш-обработчики (`#demo`) вызывать в конце скрипта, после присвоения
  всех `var`-справочников.
- **`<b>` внутри grid-элемента становится отдельной grid-ячейкой** и рвёт
  колонку в одну букву на строку — содержимое `li` оборачивать в `span`.
- **Инлайновые `<span>` не переносят строку** от `margin-bottom`: заголовок
  и текст в списке новостей требуют `display: block`.
- `white-space: nowrap` на длинной метке даёт горизонтальное переполнение
  на 390 px — метку `.tofill` переносить, `box-decoration-break: clone`.
- Дети grid (`.cols2 > *`, `.tw`) без `min-width: 0` не дают таблице
  скроллиться внутри `overflow-x: auto` — она вылезает за экран.
- Панель браузера в Claude Code отдаёт `innerWidth: 0` → мерить вёрстку
  только headless Chrome (в этой работе — iframe-харнесс + `--dump-dom`).
