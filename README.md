Знак бренда — плита с арочной фрезеровкой: один SVG-путь с `fill-rule: evenodd`,
прорезь сквозная, плита красится через `currentColor`, поэтому один и тот же знак

Подпись «мебельные фасады» подогнана по ширине слова «КАТАЛЕЯ» (разница 0 px на
семи ширинах). Фавикон `favicon.svg` — тот же путь в hex-цветах.

Общие части: `site.css` (Oswald + IBM Plex, бумажный грунт, зелёный акцент
их действующего бренда), `site.js` (мобильное меню), `stati.js` (реестр

материалы»). Шапка, подвал и хлебные крошки одинаковые на всех страницах;
текущий раздел отмечен `aria-current`.

### Блог: раскладка перенесена с «Монолита»
Рубрики со счётчиками → свежая запись крупным планом → сетка 3 в ряд, в
каждой карточке рубрика · дата (или «черновик») · время чтения (180 слов
в минуту). Фильтр по рубрике работает на клиенте и пишется в адрес
(`novosti.html?t=tech`), меняя h1, лид, крошку и `<title>` — как на
серверных страницах рубрик у «Монолита». Цвета, шрифты и радиусы свои.

**Наполнение честное:** реальная запись фабрики одна (10.02.2025), пять
разборов помечены «черновик» — они собраны на проверенных фактах
(техкарты каталога, раздел «Вопрос–ответ» их сайта, данные о плёнке) и
публикуются после того, как КАТАЛЕЯ утвердит текст. Это сказано и в
шапке-протобаре, и строкой над лентой.

**Для прода:** каждая статья — отдельный файл со своими title/description
(не `?a=slug` с подстановкой мета через JS) — чтобы структура один в один
переносилась в CMS.

## Кабинет и админка
- `cabinet.html` — кабинет партнёра: вход/регистрация, спецификация с
  валидацией по техкарте выбранной фрезеровки, декоры с наличием, мои
  заказы со статусами и повтором, документы, акт сверки (печать).

  **У каждого контрагента свой вход** — компанию и её скидку определяет
  учётная запись, под которой вошли, а не переключатель на экране.

  | Логин | Пароль | Кто входит | Цена |
  |---|---|---|---|
  | `admin` | `admin` | Дизайн-бюро «Артель» | базовая |
  | `admin2` | `admin2` | Мебельный цех «Ясень» | со скидкой 50% |

  Черновик спецификации хранится по контрагенту: переживает перезагрузку и
  не переносится на другой вход. Пароль совпадает с логином. Синонимы `1` и `2` работают так же
  (`1`/`1`, `2`/`2`). Регистр логина не важен. Неверная пара даёт ошибку и
  внутрь не пускает. Быстрые ссылки для показа минуют форму:
  `cabinet.html#demo` и `cabinet.html#demo-dd`.

  Полосы «прототип» в кабинете нет — экран показывают клиенту как есть.
  Вместе с ней со страницы ушла оговорка, что цены и наличие условные;
  она остаётся в этом README и в плане.
- `admin.html` — экран менеджера: заказы, смена статуса, KPI,
  «заказ от имени контрагента» (демо).

## Грабли
- URL CDN содержит скобки → в CSS `url()` кавычить; **в инлайновом
  `style="…"` двойные кавычки внутри двойных рвут атрибут** — атрибут
  собирать с одинарными.
- Из карточек Nethouse `src` тянуть до пробела: там srcset «URL 1x, URL 2x».
- Хэш-обработчики (`#demo`) вызывать в конце скрипта, после присвоения
  всех `var`-справочников.
- **`<b>` внутри grid-элемента становится отдельной grid-ячейкой** и рвёт
  колонку в одну букву на строку — содержимое `li` оборачивать в `span`.
- **Инлайновые `<span>` не переносят строку** от `margin-bottom`: заголовок
  и текст в списке новостей требуют `display: block`.
- `white-space: nowrap` на длинной метке даёт горизонтальное переполнение
  на 390 px — метку `.tofill` переносить, `box-decoration-break: clone`.
- Дети grid (`.cols2 > *`, `.tw`) без `min-width: 0` не дают таблице
  скроллиться внутри `overflow-x: auto` — она вылезает за экран.
- Панель браузера в Claude Code отдаёт `innerWidth: 0` → мерить вёрстку
  только headless Chrome (в этой работе — iframe-харнесс + `--dump-dom`).
