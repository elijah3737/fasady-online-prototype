# КАТАЛЕЯ — прототип мини-сайта и кабинета партнёра

**Живая версия:** https://elijah3737.github.io/fasady-online-prototype/

Прототип v3 (20.08.2026) по плану `../ПЛАН-системы-2026-08-20.md`. Двe части:

## Публичный мини-сайт
- `index.html` — главная: герой на реальном фото фабрики, демо-конфигуратор
  без цены (валидация по настоящим техкартам), группы декоров, наличие,
  производство, шаги заказа, портфолио, контакты двух городов.
- `dekory.html` — каталог 582 декоров: группы, поиск, «только в наличии»,
  карточка декора.
- `frezerovki.html` — 79 фрезеровок с фото и техкартами (лимиты по типам,
  кромка, отступы, рамка витрины).
- `politika.html` — политика ПД (проект документа).
- `site.css` — общие стили публичной части (Oswald + IBM Plex, бумажный грунт,
  зелёный акцент их действующего бренда).

## Кабинет и админка
- `cabinet.html` — кабинет партнёра: вход/регистрация (демо — за двух
  контрагентов, второй со скидкой 50%), спецификация
  с валидацией по техкарте выбранной фрезеровки, декоры с наличием,
  мои заказы со статусами и повтором, документы, акт сверки (печать).
  Прямые ссылки: `cabinet.html#demo` (базовая цена), `#demo-dd` (со скидкой).
- `admin.html` — экран менеджера: заказы, смена статуса, KPI,
  «заказ от имени контрагента» (демо).

## Данные
- `dekory.js` — 582 реальных декора с fasad-kat.ru (образцы — CDN их сайта).
  Цены УСЛОВНЫЕ; реальный прайс не публикуется.
- `frezerovki.js` — 79 фрезеровок с техкартами, снято 20.08.2026
  (мусор старого каталога отброшен: 12 «Товар», 7 «(копия)»).

## Грабли (дополнение к прежним)
- URL CDN содержит скобки → в CSS `url()` кавычить; **в инлайновом
  `style="…"` двойные кавычки внутри двойных рвут атрибут** — атрибут
  собирать с одинарными.
- Из карточек Nethouse `src` тянуть до пробела: там srcset «URL 1x, URL 2x».
- Хэш-обработчики (`#demo`) вызывать в конце скрипта, после присвоения
  всех `var`-справочников.
